# 官方来源抓取边界

这里放首批数据接入脚本。抓取器必须先读取 `data/source-registry.json`，只访问登记的官方域名；每条记录都写回 `sourceId`、`officialUrl`、`verifiedAt` 和 `needsReview`。

安全约束：

- 先检查 `robots.txt`，尊重站点规则与限速；
- 收到 401、403、429、登录墙、验证码或连续失败时立即停止该来源；
- 只提取竞赛元数据和官网/报名链接，不下载或缓存附件；
- 新旧日期冲突时保留旧记录并标记 `needsReview`，不静默覆盖；
- 抓取失败保留上一次成功数据，并在界面显示来源状态。

首批人工复核顺序：教育部/政府平台 → 竞赛组委会或学会官网 → 赛事官方站点。来源的“国家级”“含金量”和难度标签不由站点名称自动推断，必须保留证据并进入审核队列。
