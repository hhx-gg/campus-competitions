# 杜绝信息差——大学生友好竞赛消息工具

当前桌面版本为 0.6.0。应用通过 Cloudflare 中央数据接口每日检查赛事数据；服务器每天分两批检查已登记的 85 个官方 HTTPS 来源（82 个可监测网页、3 个保留下载用途的 PDF），并在校验通过后发布统一数据包。抓取失败时，服务器和客户端都会保留上一版有效数据。桌面程序另使用 Tauri 签名升级包在启动时及每 6 小时检查应用版本。

面向 Windows 10/11 的本地优先竞赛信息桌面应用。它集中展示竞赛来源、报名时间、赛程、收藏和参赛计划，不做个性化推荐。

## 当前使用

```powershell
npm install
npm run tauri dev
```

构建安装包：

```powershell
npm run tauri build
```

正式发布时使用 `tools/build-release.ps1`，它会构建安装包、用本机私钥生成 Tauri 升级签名并整理唯一最新版发布文件。

需要 Node.js、Rust stable-msvc，以及 Visual Studio 的“使用 C++ 的桌面开发”工作负载。

## 数据原则

- 只发布能够追溯到官方页面的记录。
- 日期或来源冲突的记录进入待审核队列，不覆盖已发布数据。
- 附件只提供官网下载链接，不在应用内缓存。
- 官方页面没有明确提供 2026 文件直链时，只显示“通知页”，不冒充可下载文件。
- 收藏、隐藏、备注和参赛计划仅保存在本机。
- 官方站点公开图标会随安装包本地提供；未公开或无法合法取得图标时显示非圆形文字标识，不生成假 Logo。

数据门当前为 450 条逐届记录、150 个品牌、2024—2026 各 150 条。日期精度分为精确日期、仅月份和年度已归档；只有公开材料明确支持到日时才标记为精确日期。
